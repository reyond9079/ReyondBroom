# Reyond's GLSL Shader Pack

FTE-only original shaders, MIT licensed. Install through **Assets > Shaders** in ReyondBroom's **FTE Custom game** profile. Other game profiles do not expose the pack.

The Material browser collection **textures/reyondpack** contains ocean water, procedural sky, rain puddles, fog, fire, explosion, ambient-irradiance material, snow and ice. Apply them like any material. Flame/explosion materials are intended for vertical effect cards; they do not create physical brush fire or damage.

The Assets window controls time, latitude, directional clouds, clear/cloudy/rain, four seasons, snow/ice, Moon phase and optics. Save preserves editor settings. Rain, snow accumulation, ice and camera optics use the included optional QC integration and are previewed by the editor. SDK integration is required for these effects in an arbitrary game; this pack never replaces a mod's progs.dat or csprogs.dat.

Use **Export pack to mod** to copy namespaced assets and settings into your selected runtime mod without replacing game logic. Include `sdk/reyond-pack.qc` in your CSQC source, call `RSPFrame()` before renderscene and `RSPFinish()` immediately afterward, and execute `reyond-pack.cfg` for the saved settings. Native FTE reflection/refraction are planar approximations. Water normals animate; this version does not displace the collision surface. Ice has no collision. Baked map lighting is not regenerated by changing weather.

See PROVENANCE.md and LICENSE.txt. There are no non-commercial reference shaders in this archive.
