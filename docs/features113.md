# Alpha 113: viewport controls, generators and interactive lessons

## Viewport text and themes

**Edit > Preferences > View**, or **Workspace > Appearance**, has separate pixel
sizes for coordinate/dimension labels and entity/group names (8–40 pixels).
Changing the size updates the selected label background and the accelerated
cached label path immediately. Preferences save both settings. Theme **Quake**
uses an original dark stone / brown / brass / ember palette and is also available
under **View > Interface theme** and during first-time setup.

Type and Sort share a row in the entity browser. Floating dialogs are expanded
when opened and clamped inside the editor; large forms retain their scrollbars.
Generator plugins keep their primary actions at the top, so expanding advanced
parameters does not hide those actions below the form.

## Shader-pack island

Choose **FTE Custom game**, download/activate **Assets > Shaders > Reyond's GLSL
Shader Pack**, then choose **Open sample island** in that window. The ordinary
unsaved-map confirmation protects the current document. The island, original
ground textures, ocean and complete sky shell are bundled with the editor.
Use the shader settings for time, clouds, latitude, weather and seasons.
The scene is `maps/reyond-island-sample.map`; use Save As to keep your own copy.
The original sample and textures are generated by `scripts/generate-sample-scenes.py`.
MAP water reflects the procedural sky and uses transparency for underwater
geometry; BSP water retains its engine reflection/refraction passes. MAP sky
uses a mesh-compatible preview without the BSP sky flag. Raw MAP lighting
does not add baked shadows. Game weather still requires the optional QC SDK.

## Procedural Level Generator

Open **Plugins > Procedural Level Generator**. Configure Seed, Rooms, room width
and height, corridor width/length and Origin X/Y/Z. Ceilings create enclosed rooms;
lights and a profile-appropriate player start are optional. **Generate preview**
draws green outlines without changing the document. **Apply to map** inserts the
layout at its configured coordinates and selects its objects. Undo reverses the
entire import, and Redo restores it.

Room placement forms a connected tree on a cell grid, with optional extra links.
Corridors join door openings in adjacent rooms. Limits are 2–64 rooms and 2,000
brushes; dimensions and coordinates are validated before insertion. Existing
map geometry can overlap the new layout, so choose a free origin. The generator
uses the current new-brush material. It creates geometry, not game-specific
encounters, exits or gameplay objectives.

## Ivy Grower

Select the brushes or patches the ivy should climb and open **Plugins > Ivy Grower**.
**Root at selection base** finds a starting point on the front/lower surface;
disable it to enter a world-space root. **Grow** captures the selected surfaces
and displays green preview tendrils. **Stop** keeps the current result; **Clear
preview** discards it. Growth runs in bounded batches while the editor responds.

Seed is repeatable. Iterations, maximum branches and Growth step control detail.
**Advanced growth** exposes primary-direction inertia, random influence,
surface adhesion, upward phototropism, gravity, branch probability and maximum
floating length. The triangle acceleration tree is built once per growth run.
Growth is capped at 1,800 nodes (900 for combined brush output). It stops on the node/iteration budget or when all tendrils die.

Branches and leaves can be enabled separately. Adjust branch radius, leaf size,
density and variation, then choose **Create ivy**:

- **Textured OBJ model** creates one model with original generated bark/leaf
  textures, retaining its root and world scale. OBJ/MTL/TGA assets are written
  under `models/reyond-plugins` and `textures/reyond-plugins` in the editor and
  copied to the configured mod and, for FTE Custom, the authoring resource folder when available. FTE supports OBJ directly; a
  vanilla Quake target needs conversion to MDL. Quake III can use its model path.
- **Brush geometry** inserts convex branch/leaf pieces using the current brush
  material, for game-native geometry without model conversion. This output has
  a 1,800-piece limit; reduce detail if necessary.

Undo removes the inserted map objects; reusable generated asset files remain.
The plugin follows the public Ivy Grower workflow and classic growth forces,
with an independent implementation. It does not include Cinema 4D code/assets
or promise compatibility with Cinema 4D presets, animation or its node system.
References: [Thomas Luft's original explanation](https://graphics.uni-konstanz.de/~luft/ivy_generator/),
[Maxon's surface growth settings](https://help.maxon.net/c4d/en-us/Content/html/COM_ROCKETLASSO_NEUTRON_ASSET_GENERATOR_IVY-ATTR_G3JV_QSSCNXMRV6ZDZYUWJ.html).

## Sculpt

Expand the extra tools and select **Sculpt**. Drag with LMB over brush vertices;
Raise/Lower moves them along the hit surface normal, while Smooth averages local
heights. Radius sets the affected area and Intensity the displacement per sample.
Prevent collapse preserves the rear surface and rejects collapsed geometry.
One drag is one Undo; Escape cancels the stroke.

Sculpt changes existing vertices. A large flat face has no vertices in its
middle, so a small brush there changes nothing. Increase Radius to reach its
corners, or select the brush and use **Subdivide selected brushes...** (XY plane
for ground), then sculpt the resulting pieces. Neighboring shared vertices move
together. This brush-based workflow is supported in Quake 1 as well as the other
profiles; it does not require FTE Engine terrain. Invalid convex geometry is
rejected rather than creating concave brushes.

## Interactive onboarding

After first-time resource setup, new users are offered a short optional lesson.
It opens a disposable scene with the standard panels hidden. **Skip onboarding**
is always available. Camera practice checks actual movement and looking. Create,
move, Alt-vertical move and left-Shift extrude show an animated demonstration
cursor with its pressed LMB/modifier, then wait for a real user operation.
Wheel practice checks an actual grid change. The final step shows the Tools
location before opening a normal starter scene with the full interface.

Repeat the lesson through **Help > Interactive onboarding...**. Normal unsaved
changes are confirmed first. The lesson uses separate MAPs and is not added to
recent maps. Finishing or skipping restores grid/view settings. The completion
choice is saved locally in `ftebroom/onboarding-v1.txt`.

## Validation and checks to try

The release checks exercised all practice steps through ordinary editor input,
Sculpt Raise/Smooth/shared vertices/collapse protection/Undo/cancel, the level
preview/import/Undo/Redo, ivy preview and textured OBJ placement, and plugin
primary-button visibility. Windows, Linux native and Linux SDL2 each passed 34
checks. Linux execution used WSL with Mesa software rendering; this is not a
native Arch/KDE certification. Growth BVH/determinism/collision/budget checks
also passed with Windows and Linux compilers.

Try changing both label sizes and restarting, Quake theme, opening dialogs on a
small screen, replaying/skipping onboarding, the island day/night/weather
controls, several generator seeds/origins and Undo/Redo, and ivy on a wall and
patch with both output modes. Test Sculpt on subdivided ground, including Escape
and Undo. Existing MAPs and external game resources are not rewritten by the
lesson or sample scene; use Save As to retain a modified copy.
