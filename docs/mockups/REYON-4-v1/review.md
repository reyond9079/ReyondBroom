# REYON-4 — Sound Editor, макет v1 на согласование

Дата: 2026-11-06. Статус: **ожидает подтверждения пользователя**.
[Задача REYON-4](https://reyond.atlassian.net/browse/REYON-4).
Основание: [спецификация REYON-3](../../specs/REYON-3-sound-editor-capcut-spec-prompt.md).

Это статический дизайн-прототип, а не работающая замена Sound Editor.
Волны, значения уровня и файлы демонстрационные. В HTML работают переходы между
состояниями; воспроизведения, DSP, записи, сохранения и экспорта аудио здесь нет.
Существующие native-код, аудиодвижок и клавиши ReyondBroom не изменялись.

## Просмотр

Откройте `index.html?review=1` в браузере: справа снизу появится переключатель
состояний. Также работают вкладки Basic / Voice changer / Speed и кнопки Menu,
Shortcut, Export, микрофон. Это переходы по макету, не операции с файлами.
В браузерах, ограничивающих file URL, запустите из папки:

```sh
python3 -m http.server 8764 --bind 127.0.0.1
# http://127.0.0.1:8764/index.html?review=1
```

В архиве нет внешних JS/CSS, сетевых шрифтов или аудио; для просмотра они не нужны.
`reference-passport.json` хранит ссылки и хеши внешних референсов.

## Эталон, который предлагается утвердить

CapCut Desktop для Windows, English, Dark, набор публичных официальных референсов
`CC-DESKTOP-AUDIO-2026-11-06`, перечисленный в `reference-passport.json`.
Основной геометрический референс R1a — аудиоклип и вкладка Speed, 1280×679.
Дополнительный R4a показывает обработку аудио выбранного видеоклипа; его другой
набор верхних вкладок не смешивается с аудио-only раскладкой R1a.

Точный build CapCut на этих снимках отсутствует. Установленный CapCut не запускался,
полный стандартный shortcut preset не снят. Поэтому макет не заявляется точной
копией неизвестной текущей сборки CapCut. Фиксировать эти данные выдуманным номером
или объявлять все клавиши совпадающими нельзя.

Публичный набор и предложенные ниже адаптации могут стать эталоном реализации
**только после явного согласия пользователя**. Альтернатива: выбрать конкретную
сборку/набор пользовательских снимков и скорректировать v1 до реализации.

## Карта расположения

Библиотека занимает левую верхнюю область, Player — центральную, инспектор — правую.
Пропорции ширины верхних зон: 44.5 : 29.5 : 26. Таймлайн на всю ширину снизу.
Menu слева сверху, имя проекта по центру, Layout / Shortcut / Export справа.
Media / Audio оставлены первыми слева. Справа порядок Basic → Voice changer → Speed.
Play и время остаются под Player. Timeline tools слева над линейкой; запись,
переключатели монтажа и масштаб — справа над линейкой. Заголовки дорожек — слева.

Полная карта **71 действия этого предложения**: `buttons.csv`.
Это инвентарь будущего интерфейса v1, а не заверенный полный инвентарь всех версий
CapCut. У каждой строки указан уровень подтверждения и предлагаемое место.
Подробный внутренний порядок toolbar вне явно видимых элементов ещё требует
сверки либо принятия этой версии пользователем.

## Отличия и решения, на которые запрашивается согласие

| ID | Решение v1 | Почему это нужно явно утвердить |
| --- | --- | --- |
| D1 | Взять публичные desktop-референсы как эталон вместо неизвестного номера сборки | Нельзя гарантировать совпадение всех кнопок/keys с вашей установленной версией |
| D2 | Оставить геометрию верхних зон и таймлайна; не добавлять вкладки видео/стикеров/фильтров изображения | Это специализированный аудиоредактор, а не весь видеоредактор CapCut |
| D3 | В Player показывать обзор выходной волны/метры, добавить Stop и master gain | Центральный видеомонитор адаптируется для audio-only; добавленные controls не подтверждены как расположение CapCut |
| D4 | Время показывать в секундах/миллисекундах; стрелки ±10 ms, Shift+стрелки ±100 ms | Видеопокадровый шаг CapCut не имеет однозначного значения в аудиопроекте |
| D5 | Media — локальные mod/authoring ресурсы, PAK members; без облачной stock-библиотеки | Сохраняется интеграция ReyondBroom и работа с игровыми ресурсами |
| D6 | Дорожки имеют названия и lock / visibility / mute; дополнительный Solo | Solo и расширенные заголовки являются предложением, не подтверждённой копией референса |
| D7 | Visibility скрывает waveform, но не звук; mute отдельно влияет на preview/export | Аудио-only значение visibility нуждается в определении; скрытый звук не должен случайно исчезать из экспорта |
| D8 | Voice changer: Original, Low pitch, High pitch, Radio, Echo, Tremolo; Enhance voice — локальная цепочка обработки | Это собственные DSP, не имитация закрытых AI-моделей CapCut; точные параметры будут реальными и тестируемыми |
| D9 | Save Project, Export Mix/Range и Update source with backup — три разных действия | Проект не должен неожиданно перезаписывать исходный WAV/PAK member |
| D10 | Принять предложенный preset из `shortcuts.csv` либо сначала сверить его с выбранной сборкой | Проверены только базовые команды по первичным материалам; остальные помечены proposal/verification |
| D11 | Первый визуальный эталон — Dark; native light/retro используют свои палитры при той же компоновке | Точные цветовые варианты других тем ещё не нарисованы; перед выпуском нужна визуальная проверка этих тем |
| D12 | Magnet, linkage и preview-axis реализовать с явно описанным audio-only поведением в каталоге либо уточнить по CapCut | Семантика переключателей не доказана по одним иконкам |

Важные значения v1: Solo не снимает lock; mute имеет приоритет над Solo.
Linkage перемещает связанные клипы вместе; lock блокирует групповую операцию, если
иначе нарушится взаимный интервал. Magnet закрывает разрывы главной дорожки только
в пределах разрешённого редактирования; ripple затрагивает выбранные незаблокированные
дорожки. Toggle выключен — эффект не применяется. Preview-axis по предложению
показывает hover-линию без перемещения playhead. Это предлагаемые определения,
а не заявление о подтверждённом поведении CapCut.

## Горячие клавиши

`shortcuts.csv`: 71 action ID, контекст, клавиши, source/status и поведение.
Пустое поле primary/secondary — намеренно без назначения в предлагаемом preset;
оно не означает, что проверено отсутствие клавиши в CapCut. Все 71 строки имеют
соответствие в `buttons.csv`, включая действия контекстного меню без отдельной кнопки.

Подтверждённая основа: Space, Ctrl+B, стрелки, I/O; Shift+X упомянут официально,
но конкретное взаимодействие выбора диапазона требует уточнения. A/B, Q/W,
Ctrl+Shift+B, Ctrl+Z/Shift+Z, Ctrl+C/X/V/D, Ctrl+G/Shift+G, Ctrl+S/E/I/N/O,
zoom/fit и маркеры здесь — **предложения**, не проверенный полный preset CapCut.

Приоритет ввода: диалог → поле текста → audio context → карта. Вписывание пробела
в имя не запускает playback; Ctrl+Z в поле отменяет текст, в timeline — аудио.
Ctrl+B при аудиофокусе не запускает build карты. Русская раскладка: предлагаем
физические позиции латинских клавиш для audio-команд вне полей текста, с явным
показом назначений в tooltip и настройками переназначения.

## Предлагаемый объём после согласования

| Группа из спеки | Входит |
| --- | --- |
| A01–A05 | WAV/OGG/MP3/FLAC; source library; многодорожечность; multiselect; split/trim/move; lock; история |
| A06–A07 | Transport, seek, ruler, In/Out, zoom/fit, snapping/magnet/linkage и согласованное ripple-поведение |
| A08–A10 | Gain клипа/master, mute/solo, fades, ключи громкости |
| A11 | Speed 0.25–4× и режимы сохранения / изменения высоты, включая legacy-сценарий |
| A12 | Normalize loudness: локальный двухпроходный анализ; профиль −16 LUFS, ceiling −1 dBTP как предложение |
| A13 | Reduce noise, локальный Enhance voice, перечисленные локальные Voice filters с bypass |
| A14 | Запись с выбором входа, countdown, mute проекта, новый источник/клип |
| A15 | Export всего mix или диапазона, WAV/OGG/MP3/FLAC; параметры rate/channels/codec |
| A16–A18 | Проект, autosave/recovery, relink, backup/PAK, фокус и согласованный каталог клавиш |

Не включать без отдельного решения: облачные голоса/музыку, proprietary AI voice
models, vocal isolation, speech-to-song, распознавание речи/субтитры, авто-биты,
видеоредактирование и публикацию в соцсети. Извлечение аудио из видео и AAC/M4A —
отдельное расширение, не замена текущих четырёх форматов.

Backend после утверждения: общий float32 audio graph для preview/export, FFmpeg
для codec/filter задач; `loudnorm` для нормализации; time stretch для сохранения
высоты; локальные denoise/filter/compression chains с проверкой доступности на
Windows и Linux. Никаких активных заглушек вместо DSP. Если native sound API не
позволит нужную синхронизацию/запись, предъявить варианты до смены backend.

Прежняя защита ресурсов обязательна: разрешённые roots, проверка fingerprint перед
записью, резервная копия и атомарная замена файла/PAK member. Ошибка, отказ устройства
или потерянный источник не меняют исходник; Save Project не вызывает overwrite.

## Проверено на этапе макета

- 11 состояний на 1920×1080 / 1280×800; три дорожки и четыре клипа.
- Нет горизонтального переполнения страницы, три верхних panel-зоны сохраняются.
- Переходы Basic / Voice changer / Speed, Export и Shortcut без page errors.
- Inspector и библиотека имеют независимую прокрутку; dialog помещается в viewport.
- Дополнительные raster-density 150/200% previews, прокрутка длинного инспектора.
- Автоматическая сверка каталогов: уникальные action IDs, одинаковые наборы ID
  в buttons/shortcuts, отсутствие неотмеченных дубликатов клавиш в одном контексте.

Не проверялось и не заявляется: настоящий звук, DSP, экспорт/запись, native input,
производительность и полное совпадение с неизвестным CapCut build. Код приложения
будет меняться только после согласования; аудиопроверки выполняются по разделу 9 спеки.

## Требуемый ответ пользователя

Предлагается подтвердить: **«Утверждаю макет REYON-4 v1, публичный desktop-эталон,
отличия D1–D12 и предложенный каталог клавиш»**, либо перечислить изменения.
Если важна точная конкретная версия CapCut, сначала выбрать её/снимки и сверить
клавиши, а затем представить новую версию макета.

До однозначного подтверждения этого пакета реализация не начинается. REYON-4
остаётся незавершённой; после ответа в Jira фиксируются версия и само подтверждение.
