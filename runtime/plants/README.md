# Offline botanical presets

`builtin/catalog.json` is generated by `scripts/build-plant-catalog.py` and
embedded in `native/plant/catalog_data.h` from the same source. It contains 121
stable species IDs, family-specific architectural and organ parameters, Latin
names, habitat tags and category minima. The original thirty IDs remain valid.
Seed, color or quality variants are not counted as additional species.

The descriptor data and generator code are original ReyondBroom work under
GPL-3.0-or-later. They contain no external plant models, image textures or
commercial-generator assets. `docs/plant-editor-references.md` records the
product documentation consulted. Do not replace old project generatorVersion
fields automatically: opening generator 1 must reproduce its original output.
